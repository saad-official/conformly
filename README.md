# Conformly

**EU storefront compliance, checked and watched.** One URL in. A pass/fail matrix out: withdrawal function, green claims, accessibility statement, AI-chatbot disclosure, cookie-consent parity and legal notice, each with evidence, the legal citation and a copy-paste fix. Monthly re-scans on Pro.

Part of the [Vibe Build Series](https://github.com/saad-official/vibe-build-series). Status: spec written, build starting after CertChase ships. See [docs/spec.md](docs/spec.md).

Conformly reports issues found with citations. It never says "compliant" and it is not legal advice.
